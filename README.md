# About system
-Designed primarily for the elder patients managing chronic, long-term illnesses.
-Automate medication management to improve patient adherence

# KEY FEATURES
-Real-Time Tracking: Automatically records daily medication intake and updates inventory levels.
-Predictive Analytics: AI calculates the "forget probability" of the next dose
-Smart Restock Alerts: Notifies  caregiver  automatically when the medicine supply is running low.

# System Development
-IoT Infrastructure: Integrates hardware sensors and microcontrollers with a cloud-based monitoring platform.
-Machine Learning (AI): Utilizes LSTM and Random Forest models for predictive data analysis.

# Problem statement
1. High rates of medication non-adherence and forgetfulness

2. Lack of predictive monitoring and proactive decision-making

3.Inefficient inventory monitoring and 
limited remote caregiver access

# Objective

1. To analyze current issues in medication non-adherence and review existing IoT-based pill dispenser systems to identify their limitations and technological gaps.
2.To develop an automated IoT-based pill dispenser that organizes prescriptions and provides  multi-channel reminders 
3 To implement a real-time monitoring and inventory tracking system 
4. To integrate a Machine Learning model that analyzes historical medication time-series data to predict the probability of missed doses
